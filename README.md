# 流晷计时器 Liugui Timer

> 免安装会议倒计时 —— 全屏投屏、悬浮挂件、PPT/WPS 放映自动计时。

开会控时最怕两件事：投屏看不见剩余时间，讲得投入忘了时间。流晷把这两件事一起解决了——全屏大字投出去，同时留一个置顶悬浮条挂在自己屏幕角落，PPT 或 WPS 一开始放映就自动开始倒计时。

## 下载

前往 [Releases](../../releases/latest) 下载最新的 `liugui-timer-vX.Y.Z-portable.zip`（便携版）或 `liugui-timer-vX.Y.Z.exe`（单文件）。

> 本仓库只存放安装包，不包含源代码。

## 特点

- **全屏投屏**：超大数字 + 进度环，后排也能看清
- **悬浮挂件**：置顶小窗，不挡内容，可拖动到任意角落
- **放映自动计时**：检测到 PPT / WPS 进入放映状态即自动开始
- **免安装**：解压即用，不写注册表

## 系统要求

- Windows 10 / 11（64 位）
